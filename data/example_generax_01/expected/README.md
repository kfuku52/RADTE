# GeneRax reference output

These are historical, illustrative outputs from before RADTE 0.6.0; the exact generating version was not recorded. They are not numerical golden fixtures. Earlier releases modified calibration bounds during retries, and these tables lack the fitted-age and constraint-status columns of current output. Do not use their bounds or estimated ages to assess the current bound-preserving algorithm.

Run [the current GeneRax example](../../../docs/usage.md#example-2-radte-after-generax) to generate fresh output in `results/generax/`, or select another directory with `--outdir`. Keep the input fixtures and historical files unchanged. Tests generate fresh results separately.
